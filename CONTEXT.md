# All3Rounds Archive

This glossary defines the archive's core browsing language so public routes, ingestion, and future features describe the same domain.

## Archive language

**League**:
An organizer/archive partition that owns a set of Battle records.
_Avoid_: tournament, Event

**Battle**:
A single recorded matchup that belongs to exactly one League.
_Avoid_: transcript (a Battle may have a transcript), Event

**Event**:
A named collection of Battles that belongs to exactly one League.
_Avoid_: League, Battle
